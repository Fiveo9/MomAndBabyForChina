# 孕期常见用药

> **地域说明**：正文按国内产科/药学常见沟通口径整理，**不是**某家医院处方集。各院路径、说明书与当年指南会更新。
>
> **和相邻页面的分工**：
> - [P03 营养体重与补充剂](/P03-营养体重与补充剂)：叶酸、铁、钙、DHA 等**营养向**补剂地图  
> - [P04 常见不适与红旗信号](/P04-常见不适与红旗信号)：什么时候该急诊、什么不适可先观察  
> - **本页**：各种**常见情况**下医院/药师**通常会讨论**哪些药、哪些要特别小心  
>
> **状态**：首版可用内容。**一律不写死具体毫克数与疗程**；能否用、怎么用**只听开单医师与药师**。

## 1. 先读：本页怎么用

| 你想做的事 | 本页能不能替你做 |
| --- | --- |
| 对照「感冒/发烧/便秘…通常会聊什么药」 | ✅ 可以当沟通提纲 |
| 按表格自行下单、调剂量 | ❌ 不可以 |
| 判断某种中成药/代购药是否安全 | ❌ 必须问医生/药师 |
| 慢病要不要停药 | ❌ **禁止自行停**；找专科 + 产科评估 |

### 1.1 三条铁律

1. **能不问就不自己下单**（含中成药、贴膏、口服「调理」液、海外代购）。  
2. 就诊/问药师报齐三样：**孕周（或备孕）、过敏史、正在吃的所有药与补剂**。  
3. **病比药更危险时**（高热、严重感染、未控制甲减/癫痫/高血压等），规范用药往往比硬扛更稳妥——**由医生权衡**，不是「孕期一律零药物」。

### 1.2 关于「A/B/C/D/X 分级」

- 旧版美国 FDA 字母分级在科普里仍常见，但**处方药标签已逐步改为叙述式说明（PLLR）**，不宜把字母当成唯一真理。  
- 国内说明书、医院药学咨询仍可能出现「孕妇慎用/禁用」等表述。  
- **本页不用字母给每一种药贴死标签**，改用通俗分区：

| 分区 | 含义 | 你该怎么做 |
| --- | --- | --- |
| **常讨论 / 相对熟悉** | 产科场景里经常评估使用 | 仍要剂量、疗程、禁忌听医嘱 |
| **有指征才用** | 利弊要医生现场权衡 | 不自行长期、不对照网友方 |
| **高风险 / 通常回避** | 致畸或明确母儿风险突出 | 备孕前就该问清能否换药 |
| **⏳ 院间差异大** | 路径不一 | 以建档医院书面医嘱为准 |

## 2. 按情况速查（核心表）

> 表内「常见讨论方向」= 门诊/急诊**经常会提到的成分或类别**，**不是**「可以自行购买清单」。

### 2.1 备孕与常规补充（营养向）

| 情况 | 常见讨论方向 | 注意 |
| --- | --- | --- |
| 计划妊娠 / 孕早期 | **叶酸**（必要时含叶酸的复合维生素） | 神经管缺陷预防相关；**高剂量方案仅医嘱**，勿与多种复合重复叠加 |
| 缺铁 / 贫血 | **铁剂**（口服为主；重度路径听医院） | 黑便、便秘常见；与钙/奶/茶间隔；地贫等勿乱补——见 [P02-1](/P02-1-常见检查与指标解读)、[P03](/P03-营养体重与补充剂) |
| 膳食钙不足、抽筋等 | **钙剂**（先评估膳食与原因） | 并非人人「巨量补钙」；与铁剂错开 |
| 维生素 D 缺乏 | **维生素 D** | 按化验与医嘱 |
| 深海鱼吃得少 | **DHA** 等 | 选正规来源；关注氧化与重金属宣传噱头 |
| 碘 | 加碘盐 + 膳食；甲功疾病**个体化** | 甲亢/甲减必须专科指导 |

细节与避雷见 **[P03](/P03-营养体重与补充剂)**。本页后文侧重**对症药与慢病药**。

### 2.2 孕吐 / 妊娠剧吐

| 情况 | 常见讨论方向 | 升级信号（先就医，不是先加药） |
| --- | --- | --- |
| 轻度恶心 | 生活方式：少量多餐、少油腻、避免空腹过久 | — |
| 影响进食的孕吐 | 医生可能评估 **维生素 B6**、处方止吐方案等 | 几乎无法进水、尿少、体重骤降、呕吐物带血 → 见 [P04](/P04-常见不适与红旗信号) |
| 剧吐 | **住院补液、纠正电解质、处方止吐** 等 | 勿长期只靠偏方姜茶硬扛 |

### 2.3 发热、疼痛

| 情况 | 常见讨论方向 | 特别提醒 |
| --- | --- | --- |
| 发热、头痛、轻度痛经样不适等 | 许多路径会优先评估 **对乙酰氨基酚（扑热息痛）** | **剂量上限与间隔必须按医嘱/说明书**；超量伤肝 |
| 需要抗炎镇痛时 | **非甾体抗炎药（NSAIDs，如布洛芬等）** 在孕期**限制多** | 早孕与晚孕尤其需谨慎；是否短期可用**只听医生**，勿当「备用药箱默认」 |
| 偏头痛/严重疼痛 | 专科评估；可能涉及其他处方药 | 突发剧烈头痛 + 视物模糊/上腹痛/血压高等 → **急诊**（红旗） |

> 高热、寒战不要只顾找退热药：先评估感染与脱水，**告知孕周**后再用药。

### 2.4 感冒、咳嗽、鼻塞、过敏

| 情况 | 常见讨论方向 | 特别提醒 |
| --- | --- | --- |
| 普通感冒支持治疗 | 休息、补液、物理降温；局部生理盐水洗鼻等 | **复方感冒药**成分杂（常含抗组胺、伪麻黄碱、右美沙芬等），**孕早期尤其别自行套餐式吞服** |
| 痰多 | 医生可能评估化痰药（如部分路径讨论乙酰半胱氨酸等） | 以处方/药师交代为准 |
| 鼻塞 | 生理盐水；鼻用激素等**问医生** | 含伪麻黄碱类减充血剂需专业评估 |
| 过敏（鼻炎、荨麻疹等） | 部分二代抗组胺（具体品种院内路径不同） | 「别人能吃的抗过敏药」≠ 你能吃 |
| 流感样 / 确诊流感 | 抗病毒药（如奥司他韦等）**有指征时由医生启动** | 时间窗与诊断很重要，别网购囤着乱吃 |
| 细菌感染指征明确 | 见 §2.6 抗感染 | 病毒性感冒**不是**「先吃三天抗生素」 |

### 2.5 胃灼热、便秘、痔疮

| 情况 | 常见讨论方向 | 特别提醒 |
| --- | --- | --- |
| 反酸烧心 | 少食多餐、抬高床头；医生可能评估抗酸/抑酸方案 | 胸痛放射、喘憋 → 急诊排查 |
| 便秘 | 饮水、膳食纤维、活动；医生可能评估容积性泻剂/软化剂等 | **勿长期滥用刺激性泻药** |
| 痔疮 | 坐浴、软化大便；局部制剂听医嘱 | 便血量大、脱出不能回纳、发热 → 就医 |

### 2.6 感染与抗感染药（原则）

| 方向 | 常见讨论类别（举例） | 原则 |
| --- | --- | --- |
| 相对更常评估 | **青霉素类、头孢菌素类** 等（无过敏前提下） | 按病原与药敏/经验治疗，**有疗程** |
| 需要专科权衡 | 大环内酯类、部分其他抗菌药 | 品种与孕周相关，禁止「家里剩的随便吃」 |
| 通常高风险或特殊管理 | 部分四环素类、喹诺酮类、氨基糖苷类等 | **不是绝对口号表**，但是科普里常提醒「别自行用」的类别 |
| 局部小创口/皮肤感染 | 红霉素软膏、莫匹罗星等局部药（吸收相对少） | 大面积、深部感染仍要系统评估 |
| 阴道炎等 | 按病原选局部/口服方案 | 勿自行长期冲洗 + 乱上药 |
| 尿路感染 | 孕期更积极评估治疗 | 发热腰痛血尿 → 尽快就诊 |
| 性传播感染 / 乙肝母婴阻断等 | **专用路径与药物** | 阳性结果先找开单医生要书面下一步 |

### 2.7 甲状腺

| 情况 | 常见讨论方向 | 特别提醒 |
| --- | --- | --- |
| 甲减 / 亚临床甲减等 | **左旋甲状腺素（LT4）** 是孕期管理里极常见、通常需继续的药 | **发现怀孕尽快复查**；剂量孕期常需调整；晨起空腹等服法听医嘱 |
| 甲亢 | 抗甲状腺药物**专科选药与监测** | 有致畸窗口与胎儿甲功影响，**严禁自行加减** |
| 补碘 | 与甲功状态绑定 | 见 P03；甲亢未控制时富碘限制听内分泌 |

报告怎么读见 [P02-1 §5](/P02-1-常见检查与指标解读)。

### 2.8 血糖（妊娠期糖尿病 / 孕前糖尿病）

| 情况 | 常见讨论方向 | 特别提醒 |
| --- | --- | --- |
| GDM 首选 | 医学营养治疗 + 运动 + 血糖监测 | 见 [P03](/P03-营养体重与补充剂) |
| 饮食运动不达标 | **胰岛素**在孕期使用经验多；口服降糖药是否用、用哪种**完全听专科** | 勿自行吃「降糖保健品」顶替 |
| 孕前已有糖尿病 | 备孕前就应把方案调到适宜妊娠 | 突然停药极危险 |

### 2.9 血压与子痫前期相关

| 情况 | 常见讨论方向 | 特别提醒 |
| --- | --- | --- |
| 慢性高血压 / 妊娠期高血压疾病 | 产科认可的降压方案（具体药名因人而异） | 部分常用降压药（如部分 RAS 抑制剂）**孕期通常回避**——**备孕前换药** |
| 子痫前期预防（有指征人群） | 医生可能讨论**小剂量阿司匹林**等预防策略 | **不是人人吃**；起始孕周与指征听医生 |
| 抽筋样「补钙降压」营销 | — | 不能替代正规降压与产检监测 |

头痛 + 视物模糊 + 上腹痛 + 血压升高等组合 → **急诊**。

### 2.10 皮肤、口腔、过敏性皮炎等

| 情况 | 常见讨论方向 | 特别提醒 |
| --- | --- | --- |
| 轻度湿疹/瘙痒 | 保湿；弱效外用激素等**短期、医嘱下** | 手掌脚心剧痒 + 黄疸要排查胆汁淤积等 |
| 痤疮「猛药」 | **异维 A 酸等系统维 A 酸类：备孕与孕期高风险禁区** | 备孕前停药间隔问皮肤科 |
| 牙科治疗 | 局部麻醉与抗生素在有指征时可评估 | 告知怀孕；拍片防护 |
| 真菌/细菌皮肤感染 | 局部药优先评估 | 口服抗真菌等需权衡 |

### 2.11 情绪、睡眠、精神心理用药

| 情况 | 原则 |
| --- | --- |
| 轻度失眠焦虑 | 先非药物；限制深夜搜病 |
| 抑郁/焦虑障碍、双相、精神分裂等 | **多数情况不应因怀孕擅自停精神科药物**；产科 + 精神心理/生殖精神科联合 |
| 网红助眠药/含褪黑素混搭 | 勿自行长期 |

持续情绪低落、伤人伤己念头 → 见 [P04 §5](/P04-常见不适与红旗信号)。

### 2.12 先兆流产 / 「保胎」相关（务必冷静）

| 现实 | 说明 |
| --- | --- |
| 黄体酮等 | **仅在有指征、医生开具时**使用；不是「见红就自行塞药」 |
| 止血药、中药安胎方 | 成分与证据参差；**禁止朋友圈秘方** |
| 真正要先排除的 | 宫外孕、难免流产、感染等——**先评估再谈药** |

有出血腹痛按 [P04](/P04-常见不适与红旗信号) 红旗路径走。

### 2.13 孕晚期、临产与产后衔接（扫一眼）

| 情况 | 常见讨论方向 | 备注 |
| --- | --- | --- |
| GBS 阳性 | 临产/破膜后**静脉抗生素预防** | 不等于必须剖宫产 |
| 促宫颈成熟 / 引产 / 宫缩 | 住院医嘱药物 | 居家勿模仿 |
| 产后宫缩痛、退奶/通乳、抗炎 | 住院与产后门诊方案 | 哺乳期用药另算一套，问清「能否喂奶」 |
| 继续补铁 | 产后出血/贫血时常见 | 见产后恢复章节 |

## 3. 高风险与「备孕前就要问」清单（举例）

> 下列为科普中**反复提醒**的方向，**不是完整禁药大典**。是否属于你的情况，以说明书 + 专科为准。

| 方向 | 举例（通用名/类别） | 为何常被点名 |
| --- | --- | --- |
| 系统维 A 酸类 | 异维 A 酸等 | 明确高致畸风险；备孕前需停药间隔 |
| 部分抗病毒 | 利巴韦林等 | 生殖毒性；用药期与停药后避孕要求严 |
| 抗叶酸/细胞毒 | 甲氨蝶呤等 | 致畸与流产风险 |
| 部分抗凝 | 华法林等 | 常需在备孕/孕期评估改为肝素类等路径 |
| 部分抗癫痫药 | 丙戊酸等 | 神经管等风险；**不可自行停**，要换药预案 |
| 部分降压 | ACEI / ARB 等 | 孕期胎儿肾脏等风险，备孕前常换药 |
| 他汀类降脂 | 阿托伐他汀等 | 孕期通常停用并改生活方式/专科方案 |
| 活疫苗 | 部分减毒活疫苗 | 孕期接种限制多，问医生 |
| 酒精、烟草、毒品 | — | 无「安全量」可推荐 |

**正在吃慢病药就怀孕了怎么办？**  
→ **不要吓到立刻全部停掉**（癫痫、甲减、部分抗凝/抗血小板、免疫抑制等突然停可能更危险）→ **当天或次日**联系开药专科 + 产科/生殖门诊。

## 4. 中成药、中药与「天然」

| 误区 | 更稳妥的说法 |
| --- | --- |
| 「中药没副作用」 | 成分复杂、炮制与农残、对胎儿研究往往不充分 |
| 「保胎汤人人可喝」 | 无个体辨证与指征时风险自负 |
| 「精油熏香等同理疗」 | 高浓度精油、来源不明产品谨慎；医疗用途听医嘱 |
| 「月子中心发的都能吃」 | 仍要看成分与你的孕周/过敏/慢病 |

需要中医药时：找**正规医疗机构**有资质医师，并告知全部西药与补剂。

## 5. 去药店 / 问诊前的 checklist

- [ ] 孕周或「备孕第几周」  
- [ ] 过敏史（青霉素等）  
- [ ] 正在吃的药 + 保健品 + 外用药（拍照最清楚）  
- [ ] 主要症状开始时间、体温、胎动（中晚期）、出血与否  
- [ ] 肝肾功能、甲功、血糖等近期异常（若有）  
- [ ] 想问清的三句：  
  1. 现在**必须**用药吗？不用会怎样？  
  2. 首选哪一类？有没有更熟悉孕期数据的替代？  
  3. 怎么吃、吃几天、出现什么情况要停药回诊？  

可复制口述模板见 [P04 §6](/P04-常见不适与红旗信号)。

## 6. 家庭小药箱（孕期向）建议思路

| 更合理 | 不太合理 |
| --- | --- |
| 体温计、血压计（若有指征）、干净体温记录 | 堆满复方感冒药「以备不时之需」 |
| 医生书面允许的单方退热止痛药（若已评估） | 过期药、别人剩的抗生素 |
| 生理盐水洗鼻、医用口罩、口服补液盐（医嘱场景） | 来源不明代购、网红安胎产品 |
| 当前处方药 + 补剂的**清单卡片**（入院用） | 十几种补剂叠满一桌说不清成分 |

入院待产时的慢病药清单，见 [P05](/P05-孕晚期与分娩准备)、[01 妈妈待产包](/01-妈妈待产&住院包)。

## 7. 把「药」放回产检节奏

```
不舒服
  → 先用 P04 判断：红旗？急诊？
  → 非急症：记录症状 + 孕周 + 已用补剂
  → 问建档医院产科门诊 / 药学门诊 / 急诊
  → 拿到医嘱后再购药；复盘有无与补剂重复（尤其维生素 A、铁）
  → 纸质说明书与处方留存，下次产检带上
```

化验异常后的补铁、甲减药调整，结合 **[P02-1](/P02-1-常见检查与指标解读)**。
